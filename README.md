# Raony Guimarães

**Senior Bioinformatician at [M42](https://m42.ae) · Emirati Genome Programme · Abu Dhabi**

I build the bioinformatics that turns a nation's genomes into clinical answers: population-scale whole-genome sequencing, Nextflow pipelines on Kubernetes, rare-disease and population genomics.

PhD in Bioinformatics (UFMG, Brazil). Previously in Dublin, Belo Horizonte, Ribeirão Preto and the Netherlands.

## Projects

| [Mendel,MD](https://github.com/raonyguimaraes/mendelmd) | Open-source web tool for annotating, filtering and diagnosing exomes and genomes from patients with Mendelian disorders. Live at [mendelmd.org](https://mendelmd.org). |
